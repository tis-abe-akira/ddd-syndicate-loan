# frontend: rules for AI agents

Vite + React + TypeScript + TanStack Router / Query(C-008)。構成と流儀は
[run-buddy](https://github.com/tis-abe-akira/run-buddy) のフロントエンドを踏襲する。

## 起動

ポート 3000・8080・5432 は他のアプリが使っていることがあるので避ける。

| 役割 | ポート | 起動 |
|---|---|---|
| PostgreSQL | 55432 | リポジトリのルートで `docker compose up -d --wait` |
| バックエンド | 18080 | `cd backend && ./mvnw spring-boot:run -Dspring-boot.run.profiles=dev` |
| フロントエンド | 5173 | `cd frontend && npm install && npm run dev` |

- dev プロファイルは、画面を試すためのサンプルデータ(`backend/src/main/resources/db/dev-seed`)を入れる。
- ログイン(UC-006)ができるまでは、画面上部で「操作する利用者(開発用)」を選ぶ。選んだ利用者は
  `X-Acting-User` ヘッダーでバックエンドに渡る。dev と test 以外のプロファイルでは、バックエンドはすべて拒否する。
- サンプルの融資案件: 1201(3社が応諾、ファシリティなし)、1202(応諾者なし、A1)、1203(組成中のファシリティあり、A3)。
  リード銀行はさくら銀行(利用者: 佐藤 花子)。

## Design: always follow DESIGN.md

UI work must follow [DESIGN.md](DESIGN.md). Do not invent colors, sizes, radii or spacing.

- Use the CSS variables in `src/styles/tokens.css` (they mirror the DESIGN.md YAML keys, e.g.
  `colors.surface-card` → `--color-surface-card`). Never write raw hex values in components.
- Reuse the component classes in `src/styles/global.css`, which map to DESIGN.md components
  (`.button-primary`, `.feature-card`, `.outline-card`, `.dark-card`, `.text-input`, `.badge-pill`, `.top-nav`, `.footer`).
- Coral is scarce: primary buttons and the coral callout only.
- Headings use `.display-*` (serif, weight never bold). Body and UI text use the sans. Numbers use `.numeric`.

### Adaptations of DESIGN.md

DESIGN.md describes Anthropic's Claude site. We borrow its visual language, not its brand:

- **No Anthropic spike-mark, no "Claude"/"Anthropic" wordmark.** This system has its own mark, a share pie
  (`src/components/Wordmark.tsx`).
- **Fonts** (Copernicus and StyreneB are licensed and unavailable): display = Cormorant Garamond 500 with
  Shippori Mincho for Japanese; sans = Inter with Noto Sans JP; mono = JetBrains Mono.
- **Band spacing**: an app, not a marketing page, so bands use `--spacing-xxl` (48px).
- Only the light theme exists.

## Code

- Routes (`src/routes`) fetch data with TanStack Query and pass it to components.
  Components in `src/components` take props only, so they can be tested without a network.
- The backend owns every business rule. The UI shows its answer: the fields to correct (400 `invalid-input`),
  a concurrent change (409 `concurrent-change`, start again from step 2), a rule (409 `business-rule`).
  The UI only stops input that is not a number before sending it.
- API types come from the backend's OpenAPI spec: start the backend, then run `npm run gen:api`.
  Do not edit `src/api/schema.gen.ts` by hand.
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin on `vite`/`vite build`.
- Run `npm run typecheck` and `npm test` before committing.
