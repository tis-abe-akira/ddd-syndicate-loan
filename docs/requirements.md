# 要件カタログ

シンジケートローン管理システムの要件カタログ。入力は [docs/brief/](brief/index.md)(project brief)。用語は [用語集](glossary.md) に従う。

ユーザーストーリーは「<役割>として、<目的>したい。それは<便益>ためだ。」の形で書く(英語の "As a [role], I want [goal] so that [benefit]." に当たる)。

仕様の未決事項は GitHub Issue の `[要確認]` で管理する(AGENTS.md)。

## 機能要件

|--------|-------------------------|-------------------------------------------------------------------------------------------------------------|----------|--------|
| FR-023 | 稟議の起案              | 起案者として、稟議を起案して申請したい。それは承認経路の規則で決まった承認者に判断してもらうためだ。      | High     | Open   |

| FR-026 | 報告の受け取り          | 報告先として、最終決裁で承認された稟議の報告を受け取りたい。それは決まったことを知るためだ。               | High     | Open   |
| FR-027 | 差し戻し後の再申請      | 起案者として、差し戻された稟議を修正して再申請したい。それは指摘を直して合議からやり直すためだ。            | High     | Open   |
