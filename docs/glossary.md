# 用語集

| Term                 | Definition                                                                                                     | Avoid                    |
|----------------------|----------------------------------------------------------------------------------------------------------------|--------------------------|
| シンジケートローン   | 複数の金融機関が協調し、一つの借り手に融資する仕組み。                                                         |                          |
| 融資案件             | 一つの借り手への一つのシンジケートローン。リード銀行と出資者の立場は融資案件ごとに決まる。                     | ディール                 |
| 運営 SPC             | システムを運営する特別目的会社(Special Purpose Company)。運用だけを行い、融資案件のデータは見ない。          | SCP                      |
| 利用組織             | システムを使う会社。金融機関と借り手がある。運営 SPC が登録する。                                               |                          |
| 運用管理者           | 運営 SPC の利用者で、利用組織の登録とシステムの設定を行う。                                                     |                          |
| 組織管理者           | 利用組織の利用者で、自社の利用者とロールを管理する。金融機関では、職位と承認経路の規則も設定する。             |                          |
| リード銀行           | 融資案件を組成し、借り手の審査、出資者の審査、呼びかけ、入金の記録と配分を行う金融機関。融資案件ごとの立場。 | アレンジャー、幹事銀行   |
| 出資者               | 融資案件に参加し、ファシリティの持分を持つ金融機関。融資案件ごとの立場。審査機能は使えない。                   | 投資家、貸し手           |
| 借り手               | 融資を受ける企業。融資の業務では申し込みと照会だけを行う。ロールは組織管理者、申込担当、照会担当がある。       | 債務者、ボロワー         |
| シンジケート         | 一つの融資案件に参加するリード銀行と出資者の集まり。                                                           | シンジケート団           |
| 開示情報             | リード銀行が出資者に見せる、借り手の公開情報サマリー、案件主旨、クレジットスコア、償還条件、IRR。審査の詳細は含まない。 |                          |
| クレジットスコア     | 借り手の信用度を表す指標。開示情報に含め、承認経路の規則の入力にもなる。                                       |                          |
| 信用格付             | 外部サービスが提供する、借り手の信用度の評価。審査の材料にする。                                               |                          |
| ファシリティ         | 借り手が引き出せる融資枠。コミットメント額と、出資者ごとの持分をシェアパイで持つ。                             |                          |
| コミットメント額     | ファシリティで借り手が引き出せる上限の金額。ファシリティのシェアパイの合計に等しい。                           |                          |
| ローン               | ファシリティから引き出された元本の残高。ファシリティごとに一つで、出資者ごとの持分をシェアパイで持つ。         |                          |
| シェアパイ           | 出資者ごとの持分を金額で持つ値。比率は金額から導く。ファシリティとローンがそれぞれ持ち、互いに独立して変わる。 | Share Pie                |
| 持分                 | シェアパイの中の、一つの出資者の金額。                                                                         | 持分比率                 |
| 配分                 | 一つのドローダウン・入金を、シェアパイで出資者などに按分した結果。合計は按分した金額に一致する。                 | Amount Pie               |
| 利用可能額           | ファシリティから今ドローダウンできる金額。                                                                     |                          |
| ドローダウン         | 借り手がファシリティから資金を引き出す取引。配分をローンのシェアパイに足す。                                   |                          |
| 返済予定表           | ドローダウンごとの、返済日と元本・利息の額の表。元利均等返済とバレット返済がある。                             | 返済スケジュール         |
| 入金                 | 借り手からの元本・利息・手数料の受け取り。リード銀行が記録する。                                               |                          |
| 遅延                 | 返済日を過ぎても入金のないローンの状態。                                                                       | 延滞                     |
| 稟議                 | 社内で判断を求める申請。合議、メイントラック、報告の順に進む。承認ワークフローの単位。                         |                          |
| 起案者               | 稟議を作って申請する利用者。                                                                                   |                          |
| 合議先               | メイントラックの前に、並行して稟議を審議する利用者。全員の承認でメイントラックに進む。                         |                          |
| メイントラック       | 確認者から最終決裁者まで、職位の低い順に稟議を承認していく経路。                                               |                          |
| 承認者               | メイントラックで稟議を承認・差し戻し・否決する利用者。確認者と最終決裁者を含む。                               |                          |
| 最終決裁者           | メイントラックの最後の承認者。職位は承認経路の規則で決まる。                                                   |                          |
| 報告先               | 最終決裁で承認された稟議の報告を受け取る利用者。判断はしない。                                                 |                          |
| 承認経路             | 一つの稟議の合議先・メイントラック・報告先の並び。                                                             |                          |
| 職位                 | 利用組織の中の、弱い順に並んだ階層。呼び方は各社が決める。                                                     |                          |
| 差し戻し             | 稟議を起案者に戻す判断。修正して再申請すると合議からやり直す。                                                 |                          |
| 否決                 | 稟議を終わらせる判断。同じ内容では再申請も再起案もできない。                                                   | 却下                     |
| 再起案               | 否決された稟議の条件を変えて、新しい稟議として起案すること。                                                   |                          |
| お知らせ             | 利用者の画面に届く、対応や確認を求める知らせ。                                                                 |                          |
| 引落依頼データ       | 借り手の口座から引き落とすよう銀行に依頼する、全銀協規定の口座振替の形式のファイル。                           |                          |
| 分配振込依頼データ   | 出資者の口座へ振り込むよう銀行に依頼する、全銀協規定の総合振込の形式のファイル。                               |                          |
| 銀行営業日           | 土日・祝日・12月31日〜1月3日を除く日。                                                                        |                          |
