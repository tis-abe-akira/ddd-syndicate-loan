# Use Case: 返済の入金を記録する

## Overview

**Use Case ID:** UC-019  
**Use Case Name:** 返済の入金を記録する  
**Primary Actor:** リード銀行の担当者  
**Goal:** 借り手からの元本・利息の入金を記録し、入金時点のローンのシェアパイで参加金融機関ごとの配分を決めて、ローンの元本の残高を減らす  
**Trigger:** リード銀行の担当者が、借り手からの返済の入金を確認して、記録を始める  
**Status:** Approved  

**Requirements:** [FR-015, NFR-001, NFR-002, NFR-003, NFR-009](../requirements.md)

## Preconditions

- リード銀行の担当者がログインしていて、その融資案件のリード銀行に属している。
- ローンに、実行済みのドローダウンの返済予定表がある(UC-018)。

## Main Success Scenario

1. リード銀行の担当者が、ローンの入金の記録を始める。
2. システムが、返済日が今日以前で、まだ入金を記録していない返済予定表の行を、返済日の順に示す。
3. 担当者が、行を一つ選び、入金日と入金額を入力する。
4. 担当者が、記録を確定する。
5. システムが、入金が業務ルールを満たすことを確かめる。
6. システムが、入金時点のローンのシェアパイで、その行の元本と利息をそれぞれ按分し、各参加金融機関への配分を決める。
7. システムが、入金と配分を記録し、各参加金融機関の元本の配分をローンのシェアパイから引く。
8. システムが、ローンの状態を更新する。
9. システムが、各参加金融機関への元本と利息の配分と、入金後のローンのシェアパイを示す。

## Alternative Flows

### A1: 記録する行がない

**Trigger:** 返済日が来ていて入金を記録していない行がない (step 2)  
**Flow:**

1. システムが、記録する行がないことを示す。
2. Use case ends.

### A2: 入金額が行の額と違う

**Trigger:** 入金額が、選んだ行の元本と利息の合計に等しくない (step 5)  
**Flow:**

1. システムが、行の額を示し、一部入金と超過の入金は記録できないことを示す。
2. Use case ends.

### A3: 入金日が正しくない

**Trigger:** 入金日が、今日より後か、ドローダウンの実行日より前である (step 5)  
**Flow:**

1. システムが、入金日が満たさない条件を示す。
2. Use case continues at step 3.

### A4: 記録の間に同じ行が記録された

**Trigger:** 確かめた後、記録するまでの間に、別の操作で同じ行の入金が記録されたか、ローンのシェアパイが変わった (step 7)  
**Flow:**

1. システムが、入金も配分も記録せず、別の操作で記録されたことを示す。
2. Use case continues at step 2.

### A5: 担当者が記録をやめる

**Trigger:** 担当者が、確定せずに記録をやめる (step 4)  
**Flow:**

1. システムが、入力を破棄する。
2. Use case ends.

## Postconditions

### Success Postconditions

- 入金が、選んだ返済予定表の行に対応して、入金日、元本、利息、記録した担当者とともに記録されている。
- 各参加金融機関への元本と利息の配分が記録され、元本の配分の合計は行の元本に、利息の配分の合計は行の利息に、1円の差もなく等しい。
- ローンのシェアパイの各参加金融機関の持分が、元本の配分の分だけ減っている。利息の配分では減らない。
- ローンの状態が、入金後の状態になっている。

### Failure Postconditions

- 入金も配分も記録されない。
- ローンのシェアパイと元本の残高は変わらない。
- 入金と配分とローンのシェアパイのどれか一部だけが変わることはない。

## Business Rules

### BR-001: 入金は返済予定表の行ごと

入金は、返済予定表の一つの行に対応させて記録する。入金額は、その行の元本と利息の合計に等しい。一部入金、超過の入金、返済日前の繰上返済は扱わない。

### BR-002: 一つの行に入金は一度

一つの返済予定表の行の入金は、一度だけ記録できる。

### BR-003: 入金日

入金日は今日以前で、ドローダウンの実行日以降である。

### BR-004: ローンのシェアパイで按分する

元本と利息は、それぞれ入金時点のローンのシェアパイで、UC-016 BR-005 の方法で按分する。ファシリティのシェアパイは使わない。

### BR-005: 元本だけ持分を減らす

元本の配分だけを、各参加金融機関のローンの持分から引く。利息の配分ではローンの持分は変わらない。

### BR-006: ローンの状態

初めての入金でローンは返済中になる。遅延中のローンは、返済日を過ぎて入金のない行がなくなれば返済中に戻る。元本の残高が0円になったら、ローンは完済済みになる。

### BR-007: 記録した担当者

入金を記録した担当者と日時を記録する。
